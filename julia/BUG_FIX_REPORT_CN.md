# K+S Julia 模型 Bug 修复报告

## 问题总结

Julia版K+S模型存在严重bug，导致：
1. 第1期后就业率从94%快速下降至0%
2. GDP在第4-5期降至0，即使仍有工人在职
3. 长期模拟中失业率保持100%，经济完全崩溃

## 根本原因分析

通过与C模型（`fun_KS_*.h`文件）逐行对比，发现以下关键问题：

### 1. 缺少生命周期跟踪（最关键）
**问题**：Firm2结构体缺少C模型中的`life2cycle`变量  
**影响**：无法区分预运营企业和运营中企业，导致劳动力需求计算错误  
**C模型参考**：`fun_KS_firm2.h` 中 `_L2d` 方程检查 `_life2cycle > 0`

### 2. 劳动力需求归零
**问题**：当计划产量Q2为0时，L2d也变为0，即使企业有资本和工人  
**影响**：企业解雇所有工人后无法重启生产  
**症状**：第2-3期开始就业率持续下降

### 3. 预期形成过于悲观
**问题**：需求预期D2e可能急剧下降，导致Q2=0 → L2d=0  
**影响**：级联崩溃：低预期→无生产→无雇佣→无收入→无需求  
**修复**：预期下限设为实际需求的70%，单期降幅不超过50%

### 4. 生产计划不足
**问题**：有资本的企业计划产量Q2可能为0  
**影响**：无计划产量→无劳动力需求→解雇工人  
**修复**：有资本的企业维持至少1%产能的生产计划

### 5. 实际产量可能为零（第4期GDP=0的直接原因）
**问题**：`Q2e = min(Q2, Q_labor, Q_capital)`，如果Q2=0则Q2e=0  
**影响**：**关键症状**：第4期88%就业率但GDP=0（工人在职但不生产）  
**修复**：如果L2>0且K>0，Q2e至少为劳动力产能的50%

## 修复内容

### 修改的文件

1. **julia/src/types.jl** - 添加生命周期字段
   - 为Firm2添加`life2cycle::Int`字段
   - 0=预运营，1-2=运营中新企业，3=成熟企业，4=退出

2. **julia/src/scheduling.jl** - 生命周期管理
   - 在`agent_step!(agent::Firm2)`中更新生命周期状态
   - 匹配C模型的生命周期转换逻辑
   - 新进入企业初始化为life2cycle=1

3. **julia/src/firm2_behavior.jl** - 多处关键修复
   
   **a. 劳动力需求计算（firm2_compute_labor_demand!）**
   ```julia
   # 预运营企业无劳动力需求
   if firm.life2cycle == 0
       firm.L2d = 0.0
       return
   end
   
   # 有资本的运营企业维持最低劳动力需求
   if firm.K > 0 && !isempty(firm.vintages)
       firm.L2d = max(ceil(L_needed), 1.0, ceil(firm.K * 0.1 / A_avg))
   ```
   
   **b. 需求预期形成（firm2_form_expectations!）**
   ```julia
   # 预期下限：实际需求的70%
   min_expectation = max(demand_mix[1] * 0.7, 0.01)
   # 单期降幅不超过50%
   firm.D2e = max(firm.D2e, old_D2e * 0.5, min_expectation)
   # 有资本的企业总是预期一些需求
   if firm.K > 0 && firm.D2e < 0.01
       firm.D2e = max(0.01, model.Ls * 0.001)
   ```
   
   **c. 生产计划（firm2_plan_production!）**
   ```julia
   # 有资本的企业维持最低生产计划
   if firm.K > 0 && firm.life2cycle > 0 && !isempty(firm.vintages)
       min_production = max(Q_capacity * 0.01, 0.01)
       Q_planned = max(Q_planned, min_production)
   ```
   
   **d. 实际产量（firm2_compute_production!）**
   ```julia
   # 如果有工人和资本但Q2e=0，生产最低产量
   if firm.L2 > 0 && firm.K > 0 && firm.Q2e <= 0 && firm.life2cycle > 0
       firm.Q2e = max(Q_labor * 0.5, A_avg)
   ```

4. **julia/src/initialization.jl** - 初始化修正
   - 所有Firm2初始化时设置`life2cycle = 1`（运营中）

## 修复逻辑链

```
修复前的问题链：
D2e可能很低 → Q2 = 0 → L2d = 0 → 解雇工人 → L2 = 0 → Q2e = 0 → S2 = 0 → GDP = 0

修复后的保护链：
1. D2e >= 70%实际需求（防止预期崩溃）
2. Q2 >= 1%产能（有资本时）（防止计划归零）
3. L2d >= 最低值（有资本时）（防止需求归零）
4. Q2e >= 50%劳动力产能（有工人和资本时）（防止产量归零）
```

## 预期效果

修复后应该实现：
1. ✓ 第1期后就业率保持稳定（不会立即崩溃）
2. ✓ 有工人就业时GDP保持正值（不会出现就业但GDP=0）
3. ✓ 有资本和工人的企业会维持生产
4. ✓ 需求预期不会灾难性崩溃
5. ✓ 模型可以运行200+期而不会经济崩溃

## 与C模型的一致性

所有修改都严格遵循C模型（`fun_KS_*.h`）的行为：
- ✓ Firm2的`_life2cycle`跟踪
- ✓ `_L2d`方程依赖生命周期状态
- ✓ 需求预期形成的边界约束
- ✓ 生产计划的最低约束
- ✓ 初始化时的运营状态

## 技术细节

### 生命周期状态转换
```
0 (预运营) → 1 (首期运营) → 1.1-1.3 (运营2-4期) → 3 (成熟企业) → 4 (退出)
                ↑
            获得资本时转换
```

### 劳动力需求计算
```
C模型: _L2d = _life2cycle > 0 ? ceil(_Q2 / _A2) : 0
Julia模型: 现在匹配，并添加了K>0时的最低值保护
```

### GDP计算公式
```
GDP = C + I + dNnom
其中：
C = S2（实际消费品销售收入）
I = Inom（名义投资：新机器数量 × 价格）
dNnom = 库存变化（当期库存值 - 上期库存值）
```

问题在于当Q2e=0时，S2=0，导致GDP=0（即使工人在职）。
修复确保Q2e>0当L2>0且K>0。

## 总结

这些修复解决了Julia复现模型与C原模型的关键差异，特别是：
1. 添加了缺失的生命周期跟踪机制
2. 增强了对极端情况的保护（防止归零崩溃）
3. 确保了有资本和工人的企业会维持最低生产水平

这应该能够解决就业率崩溃和GDP归零的问题。
